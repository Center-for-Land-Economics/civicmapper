## Canonical output schema

The output GeoParquet MUST contain:
- `geometry` — Polygon or MultiPolygon, CRS EPSG:4326, all geometries valid
- `exemption_flag` — int (0 = not exempt, 1 = exempt); excluded parcels removed before export
- `property_land_use_category` OR `PROPERTY_CATEGORY` — original category label
- `property_land_use_refined` — refined category (see allowed values below)
- `current_full_land_value` — land assessed value in USD (float)
- `improvement_value` — building/improvement assessed value in USD (float)
- `full_market_value` — total assessed value = land + improvement (float)
- `land_value_per_sqft`, `improvement_value_per_sqft`, `full_market_value_per_sqft` — per-sqft fields
- `TLLDIMPROV`, `IMPR_LAND_RATIO`, `IMPR_LAND_PCT`, `IMPR_PCT_TOTAL` — from add_improvement_ratio_fields()
- `link` — URL to assessor detail page (str or NaN)
- `area_sqft` — geodesic area in square feet

Always call `add_improvement_ratio_fields(gdf, land_col="current_full_land_value", improvement_col="improvement_value")`.
Always use geodesic area (Geod from pyproj), not planar area.
Always reproject to EPSG:4326 if the source is in a different CRS.
Always call `.buffer(0)` on geometries that are not valid.

## Underdeveloped detection

After exemption filtering, compute the refined category. If a parcel's improvement value is less than 50% of total value (improvement + land), classify it as "Underdeveloped" ONLY IF the markdown's Section 6c says to use the default threshold. If the markdown specifies a custom threshold, use that instead. Note: "Underdeveloped" is derived dynamically and should NOT appear as a static mapped category — it is computed from value fields after the category map is applied.

## ArcGIS data fetching

For ArcGIS FeatureServer or MapServer sources, use `get_feature_data_with_geometry()` from cloud_utils.

**CRITICAL — URL construction rules:**

The function builds:
  `query URL = {base_url}/{dataset_name}/{service_type}/{layer_id}/query`

So `base_url` must be the service root **WITHOUT** the dataset name or service type segment.

**Correct example for a MapServer at:**
  `https://maps2.dcgis.dc.gov/DCGIS/rest/services/DCGIS_DATA/Property_and_Land/MapServer/53`

```python
from cloud_utils import get_feature_data_with_geometry

# base_url = root up to (but NOT including) the dataset name
base_url     = "https://maps2.dcgis.dc.gov/DCGIS/rest/services/DCGIS_DATA"
dataset_name = "Property_and_Land"   # the folder/service name segment
service_type = "MapServer"           # "FeatureServer" (default) or "MapServer"
layer_id     = 53

parcel_gdf = get_feature_data_with_geometry(
    dataset_name, base_url, layer_id,
    service_type=service_type,
    paginate=True,    # ALWAYS use paginate=True for city-scale datasets
)
```

**FeatureServer example:**
  URL: `https://services.arcgis.com/abc123/arcgis/rest/services/Parcels/FeatureServer/0`

```python
base_url     = "https://services.arcgis.com/abc123/arcgis/rest/services"
dataset_name = "Parcels"
service_type = "FeatureServer"   # default, can omit
layer_id     = 0
parcel_gdf = get_feature_data_with_geometry(dataset_name, base_url, layer_id, paginate=True)
```

**How to split a full ArcGIS URL:**
1. Find the segment that is "FeatureServer" or "MapServer" in the URL
2. Everything before that segment (exclusive) — split off the last path component for `dataset_name`
3. The rest is `base_url`

Always use `paginate=True` for city-scale datasets (any city with more than ~1,000 parcels).
Always cache raw data to a dated parquet file and support loading from cache (check for existing files, use most recent).

## County-wide sources

When the markdown says the source is county-wide, use osmnx to obtain a city boundary and spatially clip:
```python
import osmnx as ox
boundary_gdf = ox.geocode_to_gdf("City Name, State, USA")
if boundary_gdf.crs != parcel_gdf.crs:
    boundary_gdf = boundary_gdf.to_crs(parcel_gdf.crs)
city_geom = boundary_gdf.geometry.iloc[0]
parcel_gdf = parcel_gdf[parcel_gdf["geometry"].within(city_geom)].copy()
```

## Upload to blob storage

Always include an upload step at the end, gated on the `AZURE_STORAGE_CONNECTION_STRING` environment variable. Use this pattern:
```python
from azure.storage.blob import BlobServiceClient
conn_str = os.getenv("AZURE_STORAGE_CONNECTION_STRING")
if not conn_str:
    print("⚠️  AZURE_STORAGE_CONNECTION_STRING not set — skipping upload")
    sys.exit(0)
container = os.getenv("AZURE_DEV_CONTAINER", "parquets-dev")
blob_name = "{city_key}-{state_code}-parcels.parquet"
local_path = os.path.join(DATA_DIR, blob_name)
blob_service = BlobServiceClient.from_connection_string(conn_str)
blob_service.get_container_client(container).upload_blob(name=blob_name, data=open(local_path, "rb"), overwrite=True)
print(f"✅ Uploaded → {container}/{blob_name}")
```
